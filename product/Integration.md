# Agent 与 Web 整合

本次基于 `fc0f3d9` 的原有 Agent 和本地 Web 改造整合，保留原仓库历史。主要目标是让网页实际复用原 Agent 能力，并维持单一知识库、持久会话和可核验引用。

## 统一的实现

`FinancialRAGAgent.from_retriever()` 接收检索函数和文档集合。CLI 从原有向量库创建 Agent；Web 从每次请求固定的 `ScopedSnapshot` 创建同一个 Agent 图。

意图判断、查询改写/子查询拆分、report_search、judge、有界参数修复/空结果恢复共用原节点。Web 以 prepare-only 模式完成准备，再由现有 SSE 服务执行生成和引用校验，避免生成两次。短追问通过规则补全前一问题，不把历史答案当作检索证据。

四个原子工具按 Agent 实例绑定，不再在构造时覆盖进程级全局 handler。所有实例仍共享调用并发许可、超时与临时失败重试；候选域与文档版本按请求独立，恢复不会访问 CLI 的另一套索引。工具也通过 `/api/v2/tools` 提供严格参数校验后的显式调用。

RRF 权重与原重排分数明确区分，不套用旧版 0.3 阈值。结构化查询中的必含词/过滤条件不再在零命中时悄悄返回未过滤文档。问候语夹带事实问题继续检索，单纯问候走闲聊。

## 清理

- 删除未使用的 Vite 演示组件及图片、旧前端会话 store、旧版问答请求函数；保留 SSE 组帧器供当前 API 使用，基础测试改为直接测试生产 v2 协议。
- 删除服务端旧问答 HTTP 接口、身份/角色/ACL/上传/多库管理代码及旧模式开关。数据库升级保留既有列、表及数据。
- 删除失效的认证/多库验收脚本、旧注册 CLI 和绑定本机历史镜像的回退 Compose。
- README、前端说明与当前接口文档统一；本地历史规划/阶段交付稿和截图不打包到代码仓库。
- 新增 GitHub Actions：后端离线回归、前端基础/构建/浏览器回归。密钥、PDF、索引、会话、模型缓存及测试产物不进入新提交。

## 验证范围

回归涵盖共享图的复杂子查询、规则追问、恢复次数、永久失败、RRF 判断、实例并发隔离、四个工具、文件版本、解析表格、旋转裁剪坐标、会话/引用/SSE 状态，以及无登录启动。离线评测继续区分 fixture embedding 与实际生成效果。

真实验证使用宿主机已有三份 PDF，并建立独立验收会话。不把来源匹配、少量成功案例或离线 fixture 指标称为总体准确率。复杂扫描/跨页表格与性能仍有边界，单机 SQLite/单 worker 部署保留。

2026-10-18 最终本机检查：后端 **52 项**、前端生产 API/SSE 基础 **9 项**、浏览器 **16 项**通过；类型检查与生产构建通过。固定离线 9 样本：目标文档召回 7/7、引用页/片段协议 20/20，真实事实正确率不由这些指标推断。

真实完整流程核验通过：海光 2022 年收入/归母净利润、同公司 2021 年收入追问、海光与宁德时代业务对比；最终分别有 1、1、4 个真实引用，对比覆盖两份 PDF，网页恢复三轮并实际渲染引用原文。首字分别为 13419、3377、6077 毫秒，仍未达到两秒目标。四个工具的真实目录、检索、上下文展开和 Decimal 计算均通过。

整合中保留了 2021 追问的失败记录，定位到年份切换与数值表格召回问题。修复包括：新年份替换历史年份、2021A/2024E 的词法年份对齐、文件名作为检索上下文，以及对具有明确年份列的真实表格保留少量候选后统一重排。只提到年份的图表标题不当作年份列表格；原文内容、坐标和索引文件不被改写。

本地详细 JSON/截图位于 Git 忽略的 `docker/frontend/test-artifacts/integration/` 及 `single-workspace/`，密钥和原始资料不随报告上传。

最终容器重建后复核：三份原始 PDF 全部可检索且原文 SHA256 一致，唯一库名和三轮真实验收消息保留，引用 PDF 实际渲染成功，四种桌面/手机明暗布局无整页溢出。原 `dataset/vector_store/` 三个索引文件与之前备份的 SHA256 全部相同。
